# Primeira-Automatiza-o-Excel---SAP
📌 Este foi um dos meus primeiros e mais complexos códigos em VBA com SAP Script. A automação conecta-se ao SAP GUI, acessa a transação IP24, valida dados em tempo real e extrai de forma autônoma as últimas datas de planejamento de centenas de planos para o Excel. O script reduziu o tempo de execução e eliminou falhas humanas.
